## Name

Managed App Launcher

## Description

Keep your applications in lists and launch them from any Stream Deck. The launcher profile pages through each list for you, a dot shows which apps are running, and a long press closes them. Works with shortcuts, programs, Store apps, Steam games and versioned folders.

Features:
- One app list or several, each opened from its own Open Launcher key; dedicate a deck to a list
- Automatic paging on Stream Deck, XL, Mini, + and Neo, with row and page breaks
- Running indicator, focus or relaunch on press, long press to close, optional run as administrator
- Targets that survive updates: versioned install folders (app-1.2.3) and MSI shortcuts resolve to the current build
- Launch App key to place a single app anywhere, picked from the Start menu, Steam or running apps
- Companion manager to edit lists, icons and per-app settings, and a command line (malaunch) with an optional "Pin to Stream Deck" entry in the Explorer menu

Requirements: Windows 10 or later, Stream Deck 6.9 or later. The plugin collects no data.
